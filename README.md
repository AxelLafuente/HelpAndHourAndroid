
# ⏰ HelpAndHourAndroid

Aplicativo Android desenvolvido com Jetpack Compose, baseado em um layout criado no Figma. Estrutura inicial voltada para controle de tempo ou tarefas, com navegação moderna e design responsivo.

---

## 📐 Sobre o Projeto

Este app é uma **adaptação de um layout projetado no Figma**, transformado em um aplicativo funcional com Jetpack Compose. O objetivo é praticar a implementação de interfaces modernas seguindo conceitos de UI/UX enquanto estrutura uma base sólida para futuras funcionalidades.

---

## 🛠 Tecnologias Utilizadas

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Navigation Compose**
- **Arquitetura MVVM (em andamento)**
